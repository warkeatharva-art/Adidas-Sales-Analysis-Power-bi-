# Adidas Sales Analysis Dashboard (Power BI)

## 📊 Project Overview
This project focuses on analyzing Adidas sales data using Power BI to uncover key business insights across regions, products, and time periods. The dashboard provides a comprehensive view of sales performance, profitability, and operational efficiency.

---

## 🎯 Objectives
- Analyze overall sales performance and trends  
- Identify top-performing regions and products  
- Track key metrics such as revenue, profit, and margin  
- Enable data-driven decision-making through interactive visuals  

---

## 📁 Dataset
- Source: Adidas Sales Dataset  
- Contains information on:
  - Sales revenue  
  - Product categories  
  - Regions and countries  
  - Time (monthly/yearly data)  

---

## 🛠 Tools & Technologies
- Power BI  
- DAX (Data Analysis Expressions)  
- Excel (Data Cleaning & Preparation)  

---

## 📈 Key Features of Dashboard
- Interactive filters and slicers  
- KPI cards (Total Sales, Profit, Operating Margin)  
- Region-wise and product-wise analysis  
- Time-based trend analysis  
- Visualizations: Bar charts, Line charts, Maps  

---

## 🔍 Key Insights
- Identified top-performing regions contributing the highest revenue  
- Analyzed product categories with maximum profitability  
- Observed seasonal trends in sales performance  
- Highlighted areas with lower sales for improvement opportunities  

---

## 📂 Repository Contents
- `Adidas Sales Dashboard.pbix` → Power BI file  
- `dataset.xlsx` → Dataset used
  
---

## 🚀 How to Use
1. Download the `.pbix` file  
2. Open in Power BI Desktop  
3. Explore the dashboard using filters and visuals  

---

## 📌 Conclusion
This project demonstrates the use of Power BI for transforming raw data into meaningful insights, helping businesses make informed decisions.
